# HCM Artifact Reception Field

This repository is not a generator.
It does not produce.
It does not request.
It does not optimize.

It exists to receive.

Artifacts may appear elsewhere.
If they are allowed to pass,
this field records their arrival.

No artifact is evaluated here.
No artifact is explained here.
No artifact is promoted here.

Reception does not imply continuation.
Presence does not imply value.
Return does not imply obligation.

This repository must remain quiet.
Any modification is a trace, not an action.
